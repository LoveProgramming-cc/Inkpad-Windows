# Inkpad · Windows 10 x64

双击 Inkpad.exe 打开文稿库。便携版先完整解压到可写目录。安装版默认目录为 D 盘的 Inkpad，当前用户可在 Windows「应用和功能」中卸载。

这份程序使用 当前 GNOME 项目的 Python 代码、GTK 4 和 libadwaita。包内含原生 Windows 启动器、已编译的 Python 应用字节码、可阅读的源码、Python 运行时和 Poppler。运行所需的库随包提供。

文稿库默认在程序旁的 InkpadData/library。设置和缓存也位于 InkpadData 下。卸载保留个人数据。可通过 INKPAD_HOME 指向其他专用数据目录，或在应用设置中选择已有文稿库。直接打开文件时可将 .inkpad、.pdf 或 .goodnotes 文件拖到 Inkpad.exe 上。
